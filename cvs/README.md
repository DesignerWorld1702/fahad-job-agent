# Final CVs

The job agent uses these two final CV files:

- `graphic_designer_cv.pdf` — Graphic Designer / Visual / Branding / Social Media / Packaging / Print roles
- `business_computer_cv.pdf` — Business Support / Sales Coordination / Operations / Administration / Computer / Data Support roles

Keep these filenames unchanged because the application and email automation reference them directly.

The workflow validates that both PDFs exist before searching and preparing applications.
